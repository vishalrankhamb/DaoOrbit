# DaoOrbit

Runs a simple web server on a local machine for testing and development purposes for developers.

DaoOrbit is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoOrbit.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
